# 交易工作台视觉参考（2026-08-30）

来源：用户提供的“交易网站简单模板.jpeg”。本文件只归档界面构成与信息架构，不将截图内文字或数据视为业务指令。

## 视觉语言

- 深靛蓝背景，低对比边框卡片；收益与健康状态使用柔绿，风险与异常使用暖红。
- 标题、数值和说明分三级：卡片标题 → 关键大数值 → 低饱和说明及时间。
- 以栅格卡片分隔“控制、策略、绩效、交易、监控”，避免把风险信息混入图表。

## 可复用区域

| 区域 | 目的 | 核心字段 |
| --- | --- | --- |
| 运行控制 | 告知系统与任务健康度 | 状态、运行时长、挂单数、未匹配数、下次动作 |
| 运行中计划 | 看到策略与当期表现 | 标的、方向、周期、策略状态、盈亏 |
| 绩效 | 汇总账户表现 | 已实现、浮动、平仓数、最佳标的、资金曲线 |
| 未匹配头寸 | 把需对账仓位集中到一处 | 标的、方向、周期、合并笔数、数量、加权开仓价、最新时间 |
| 事件流 | 可追溯策略关键动作 | 时间、事件类别、标的、来源、状态 |

## 本次落位：方案 B（风险优先条）

在资金曲线与交易图表之前设置两张并列卡片：左侧“未匹配头寸”，右侧“事件流”。这是独立的只读监控层。

- 未匹配头寸按 `symbol + side + timeframe` 聚合，同一策略分批成交不重复成行；数量和价格仅来自已归档成交。
- 事件流使用持久化的实盘策略、保护策略及归档订单状态；优先展示成交、策略止盈、策略止损与保护异常。
- `保护异常` 永远使用明确风险颜色和文字，不以“已保护”推断代替实际状态。
- 面板不能发起下单、撤单或修改策略；点击标的只导航至该标的交易页。
