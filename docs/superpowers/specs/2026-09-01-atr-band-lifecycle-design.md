# 1H MA30 ± 3ATR 强弱生命周期雷达

## 目标

将 MA30 ± ATR 单次筛选升级为可跨扫描持续追踪的研究雷达。系统每 3 小时扫描一次 Binance USDT 永续，使用已收盘的 1 小时 K 线判断多空强弱生命周期，并保留所有完成或失效的历史区间。

## 生命周期口径

1. 多头在连续至少 3 根 1H 收盘严格高于 `MA30 + 3 × ATR(14)` 后进入强势池。
2. 空头在连续至少 3 根 1H 收盘严格低于 `MA30 - 3 × ATR(14)` 后进入强势池。
3. 多头收盘跌回 `MA30 + 3 × ATR` 下方时转为警示；空头收盘升回 `MA30 - 3 × ATR` 上方时转为警示。
4. 警示中的多头收盘跌破 1H MA30 时结束并进入历史区；警示中的空头收盘升破 1H MA30 时结束并进入历史区。
5. 反向信号可在一个历史区间结束后创建新的、相反方向生命周期；同一时刻一个币仅有一个活动生命周期。

## 调度与幂等

- 仅在北京时间 0、3、6、9、12、15、18、21 点的 3 小时桶运行。
- 每个 3 小时桶通过最近快照的桶标识去重，维护任务被重复调用时不重复访问 Binance。
- 扫描使用全市场 USDT 永续、1H 已收盘 K 线和对应 OI；15m、4H 保留为单次发现视图，不决定此生命周期的进出。

## 归档数据

每个生命周期保存：币种、方向、首次入池时间、警示时间、结束时间、最新状态、入池价、当前价、峰值/谷值价、最大有利幅度百分比、相对 MA30 的最大 ATR 倍数、入池/当前/峰值 OI、OI 变化百分比，以及前一根收盘相对 MA30 和 ±3ATR 阈值的百分比。

## 页面

新增多头、空头、全部筛选；每个方向展示强势池、警示区、历史区。历史区保留完整的生命周期统计，不因退出强势池而删除。所有结果为只读研究信息，不连接任何交易执行路径。

## 验收

- 多头和空头均能分别从入池、警示到历史结束。
- 每 3 小时最多执行一轮全盘扫描。
- 同一生命周期可查看最高有利涨跌幅、最大 ATR 倍数、OI 轨迹和前一根 K 线偏离。
- 单元测试覆盖状态迁移、去重、指标计算和历史归档；类型检查与生产构建通过。
