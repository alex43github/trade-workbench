# AI 任务路由设计

## 目标

网站根据分析任务的风险和规模选择已验证的模型；主模型不可用时按确定顺序降级，并保存实际使用模型与降级原因。

## 任务类别

- `market_scan`：雷达、MA30 × OI、破底翻等批量初筛。默认 `deepseek-v4-flash → gpt-5.6-luna → gpt-5.6-terra`。
- `expert_consultation`：四位交易高手的单币会诊与计划汇总。默认 `gpt-5.6-terra → gpt-5.6-sol → deepseek-v4-flash`。
- `risk_review`：仓位管理、异常情况、最终复核。默认 `gpt-5.6-sol → gpt-5.6-terra → deepseek-v4-flash`。

## 模型注册表

模型使用稳定的模型 ID、通道 ID、协议和能力标签注册。任务规则引用能力标签或模型 ID，而不是业务页面中的硬编码名称；通道可以增加新模型或更新模型显示名而不修改交易流程。

## 降级规则

只选择已通过连接检测的目标。调用出现认证、额度、限流、超时或临时服务错误时，按该任务的候选顺序继续尝试；格式错误不自动切换，以免掩盖提示词或供应商兼容问题。成功结果包含实际模型，失败结果包含每次尝试的原因。

## 安全约束

API Key 不回传浏览器；路由只使用服务器已保存的凭据和已验证通道。连接验证的真实性由服务端记录并设有效期，前端不能伪造启用状态。
