# 会诊图表与交易终端风格统一设计

## 目标

把 `/consultations` 的演示柱状占位图替换为基于已落库会诊快照的 Lightweight Charts K 线图，并在专家达到明确多数共识时显示入场区间、止损和止盈参考线；同时让会诊页的卡片、字体、间距和状态样式与交易页保持同一套专业终端视觉。

## 数据与规则

- 使用 `consultation.snapshot.timeframes` 中的已收盘 `1h`、`4h`、`1d` K 线，不生成伪造行情。
- 默认显示 `1h`，用户可以切换 `1h`、`4h`、`1d`。
- 只有 `validOpinions >= 3` 且同一方向票数至少为 3 时绘制共识点位；否则只显示 K 线并提示“共识不足，不绘制确定性点位”。
- 入场使用多数方向意见的 `entryZone`，止损使用多数意见的 `stopPrice`，止盈使用 `targets`；缺少某类价格时不绘制该类线。
- 会诊页继续保持“仅建议、不下单”安全语义。

## 实现边界

- 新增客户端 `ConsultationChart`，把会诊 `ClosedBar` 映射为交易页 `MarketBar`，复用 `TradeChart` 的图表能力和价格线能力。
- 会诊页服务端只负责读取并传递可序列化的快照和共识数据；周期切换留在客户端。
- 交易终端视觉令牌只在 `advisory.module.css` 内统一，不改变交易页已有业务行为。

## 验收标准

- 页面不再显示 fake chart 或“下一迭代接入”文案。
- 页面能显示带 TradingView attribution 的 K 线、成交量和周期切换。
- 3/4 或 4/4 共识显示入场/止损/止盈参考线；分歧或不足 3 个有效意见时不显示价格线。
- 会诊页服务端渲染测试、数据转换测试和完整构建通过。
