# HyperGrid G0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver an unattended, read-only HyperEVM/PRJX V3 discovery foundation with exact price math, versioned JSON contracts, safe diagnostics, and evidence-backed G0 documentation.

**Architecture:** A capability-guarded JSON-RPC client is injected into token and PRJX V3 readers. Readers produce typed identities and a latest-block pool snapshot. `PriceMath` converts `sqrtPriceX96` using `bigint` rational arithmetic. A small CLI exposes discovery and health only. No signer, wallet, transaction, approval, or execution dependency is introduced.

**Tech Stack:** Existing Node 22+/TypeScript project, native `fetch`, native `bigint`, Node built-in test runner, no new runtime dependency.
